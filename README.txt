SUSHIL YADAV — PORTFOLIO WEBSITE

1. Unzip this folder.
2. Open index.html in a browser to preview the website.
3. To publish: create a GitHub repository, upload index.html and the assets folder,
   then import that repository into Vercel and deploy.
4. Before publishing, replace the generic LinkedIn link with your actual profile URL.
5. Check whether you want your phone number visible publicly; it is currently displayed.

All supplied certificate images and the supplied portrait are included in assets/.
The website is responsive and uses plain HTML/CSS/JavaScript; no build tools are required.
